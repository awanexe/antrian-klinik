# Klinik Naseha — Hybrid Web App (Antrean Pasien)

Sistem antrean pasien real-time dengan arsitektur **hybrid**:
- **Frontend** — Static site di Vercel (`frontend/`)
- **Proxy** — Vercel Serverless Function (`api/proxy.js`)
- **Backend API** — Google Apps Script (`backend/Code.gs`)
- **Database** — Google Sheets
